REGLAS DE TIPADO QUE ROMPEN LA COMPILACIÓN EN ESTE PROYECTO (verificadas con Godot 4.7.2, no negociables):
- Prohibido `:=`. Prohibida toda declaración sin tipo: `var x: int = 1`, `const X: int = 3`, `for i: int in range(n)`, `for k: String in dict`, `func f(a: int) -> void`, lambdas `func(x: int) -> int:`. `_init`, `_ready` y todos los `func` llevan `-> tipo`.
- `const S = preload("x.tscn")` es error; solo los `preload` de scripts se aceptan sin tipo.
- Fronteras con JSON: `var v: Variant = ...`; estrechar con `if v is Dictionary: var d: Dictionary = v`. No uses `v as Dictionary` (aviso `unsafe_cast`) ni `int(variant)` / `float(variant)` (aviso `unsafe_call_argument`): pasa por una variable tipada y usa `roundi()` para `int`.
- `@warning_ignore` solo en fronteras `Variant`, con comentario del porqué. Cero en el resto.
- Todo número JSON llega como `float`; `Object.set()` coacciona en silencio (`"nueve"` → 0) y no falla con propiedades inexistentes; valida tipos y claves ANTES de `set()`; diccionarios tipados solo con `.assign()` tras validar.
- Todo script CLI `extends SceneTree` debe llamar `quit()` en TODAS las rutas, también en fallo: un error antes de `quit()` deja el proceso colgado para siempre en headless. Ejecútalos con `timeout 120`.
